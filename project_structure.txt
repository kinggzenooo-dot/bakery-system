================================================================================
FREDY BILLS BAKERY MANAGEMENT SYSTEM - DECOUPLED ARCHITECTURE STRUCTURE
================================================================================
Architecture Model: Decoupled Multi-Service Deployment
- Frontend Host   : Vercel (Pure Static HTML5 / CSS3 / Vanilla ES6 JavaScript)
- Backend Host    : Render (FastAPI / Uvicorn ASGI Web Service)
- Database & CDN  : Supabase (PostgreSQL Database & Storage Buckets)

--------------------------------------------------------------------------------
2. DEPLOYMENT CONFIGURATIONS
--------------------------------------------------------------------------------
RENDER (Backend):
- Root Directory : backend
- Build Command  : pip install -r requirements.txt
- Start Command  : uvicorn app.main:app --host 0.0.0.0 --port $PORT

VERCEL (Frontend):
- Root Directory : frontend (or default root with root vercel.json)
- Framework Preset: Other / Static

SUPABASE (Database & CDN):
- PostgreSQL Connection string in Render -> DATABASE_URL
- Storage Bucket: 'bakery-images' (Public)

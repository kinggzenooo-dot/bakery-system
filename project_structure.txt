--------------------------------------------------------------------------------
2. ROLE-BASED PORTALS & ENTRY POINTS
--------------------------------------------------------------------------------
- index.html    : Public storefront for customer viewing and ordering.
- login.html    : Role-based authentication gate (redirects to assigned portal).
- admin.html    : Full system management (products, inventory, staff, sales, reports).
- pos.html      : Cashier & counter staff terminal for in-store order processing.
- baker.html    : Kitchen / baking queue management for batch production.
- delivery.html : Rider portal for order dispatch, pickup, and delivery confirmation.

--------------------------------------------------------------------------------
3. BACKEND ARCHITECTURE BREAKDOWN
--------------------------------------------------------------------------------
- Framework     : FastAPI (Python 3.10+) with Uvicorn ASGI server.
- Database ORM  : SQLAlchemy 2.0 with SQLite (local) or PostgreSQL (Supabase cloud).
- Authentication: OAuth2 with JWT Bearer tokens & Passlib (bcrypt) hashing.
- Routing       : Modular APIRouters split by domain under `backend/app/routers/`.

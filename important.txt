- /api/production : Kitchen batches, batch status (pending, baking, completed)
- /api/delivery   : Dispatch assignment, delivery route logs, status tags
- /api/suppliers  : Vendor directories and lead times
- /api/reports    : Financial analytics, top seller stats, daily summaries
- /api/store      : Store branches, operational hours, active promo banners
- /api/upload     : POST /upload/image (Multipart image uploads)

6. QUICK RUN & DEPLOYMENT INSTRUCTIONS
--------------------------------------------------------------------------------
A. LOCAL DEVELOPMENT RUN:
   1. Open terminal in the project directory:
      cd "d:\MSEPROJECT\bakery system"

   2. Install backend dependencies:
      pip install -r backend/requirements.txt

   3. Start backend server:
      python backend/run.py
      (or: uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload)

   4. Open web browser:
      - App Login : http://127.0.0.1:8000/static/login.html
      - API Docs  : http://127.0.0.1:8000/docs

B. PRODUCTION DEPLOYMENT CHECKLIST:
   1. Cloud Host Options:
      - Render.com / Railway.app / Fly.io for FastAPI backend
      - Vercel / Netlify / GitHub Pages for Frontend static files, OR serve through FastAPI static mounts
      - Supabase / Neon / ElephantSQL for managed PostgreSQL database
   2. Production Environment Variables:
      - Set `DATABASE_URL` to your production PostgreSQL connection string
      - Change `SECRET_KEY` to a cryptographically secure random 64-char string
      - In `js/api.js`, update `API_BASE_URL` to your live backend domain (e.g., https://api.yourdomain.com/api)
   3. Database Migration:
      - Run `schema_supabase.sql` in Supabase SQL Editor if using Supabase PostgreSQL.
